# TokiNote

TokiNote 是一款本地优先的 Android 笔记应用。你可以记录随手想法、按标签整理、沿时间线回看，也可以从底栏进入专注计时。笔记和计时状态都保存在设备本地，不需要账号或网络权限。

## 功能

笔记支持自动保存、搜索、标签、收藏、归档、撤销删除和颜色区分。主导航提供笔记、标签、时间线与专注四个入口，并适配手机、平板和大屏布局。

专注页默认提供 25 分钟专注、5 分钟短休息和 15 分钟长休息；支持开始、暂停、继续、重置、跳过阶段和自动轮换。计时截止时间与当天完成轮数保存在本机，离开专注页或重启应用后仍可恢复。应用也支持浅色和深色外观。

## 构建

使用 Android Studio 打开项目根目录；或在已配置 Android SDK 的环境中运行：

```bash
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

最低支持 Android 8.0（API 26）。笔记与专注记录只保存在设备本地；卸载应用或清除应用数据会删除这些内容，请先自行备份重要数据。
