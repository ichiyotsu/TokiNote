# TokiNote

**TokiNote 是一款安静、轻巧的 Android 原生笔记应用。** 灵感、日常计划和读书摘记，都可以留在一个只属于自己的小空间里。笔记保存在设备本地，不需要账号，也不会上传到服务器。

## 可以做什么

- 新建和编辑笔记，内容自动保存
- 搜索标题与正文，使用标签整理
- 收藏、归档、撤销删除，并为笔记挑选颜色
- 在手机上专注书写，在大屏上并排浏览与编辑
- 切换浅色或深色外观

## 运行项目

使用 Android Studio 打开仓库根目录，等待 Gradle Sync 后运行 `app`。也可以在命令行构建：

```bash
./gradlew :app:assembleDebug
```

最低支持 Android 8.0（API 26）。应用不需要网络权限；卸载应用或清除应用数据会删除本机笔记，重要内容请自行备份。

## 设计方向

界面借鉴 [Material 3 Expressive](https://m3.material.io/) 对色彩、形状、排版、动效和自适应布局的处理。半透明卡片与柔焦背景采用克制的实时模糊视觉；弹出层在系统支持时使用 Android 原生窗口模糊，并在省电、设备不支持或旧版系统上回退到更实的底色。Android 17 的模糊趋势仅作为灵感参考，相关早期报道并非正式设计规范。
